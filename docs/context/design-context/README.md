# Design context

Read the [current design context](design-context.md) after the [product context](../product-context/README.md) and [experience context](../experience-context/README.md). It records the visual proposal from the [landing](../../../landing/README.md), the interface adaptations still to design, and the source trail for future mockups.

The designer's [skill](../../../.agents/skills/create-design/SKILL.md) and [role contract](../../../.agents/agents/design-agent.md) govern future work. Put new reviewable screen mockups in `mockups/` and link them from the design context. This living context has no approval status; the landing's visual identity is a proposal, while the selected subject-led entry is a separate owner decision.

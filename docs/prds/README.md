# Product requirements

The [initial product PRD](entre-nous-initial.md) inventories discovery capabilities across the fictional demo and possible real-person service. Its 24 October baseline was approved; a later revision incorporating the owner's selected entry and optional voice (A-32) is ready for artifact review. Its demo requirements are decomposed into [reviewable features](../features/README.md). The earlier product-wide approval does not approve this revision, a scoped delivery PRD or build readiness. Use the [PRD skill](../../.agents/skills/create-prd/SKILL.md) for initial or scoped PRDs and the [feature skill](../../.agents/skills/create-features/SKILL.md) to decompose a named PRD. Trace requirements to the living [product context](../context/product-context/README.md). A scoped PRD is ready to build only when its scope is accepted and material blockers are resolved.

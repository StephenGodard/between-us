# Features

The [initial product PRD](../prds/entre-nous-initial.md) and these three demo feature specifications were explicitly approved on 25 October 2026. A-36 resolved the planned joiner exit and call hangup paths. The features appear in dependency order:

| ID | Feature | PRD requirements |
| --- | --- | --- |
| F-D-01 | [Fictional exchange and two-way chat](demo-fictional-exchange-chat.md) | D-R1, D-R4 |
| F-D-02 | [Optional real two-way audio call](demo-audio-call.md) | D-R2 |
| F-D-03 | [Close and clear the exchange](demo-exchange-closure.md) | D-R3, D-R4 boundary |

The PRD's D-R5 video is a separate delivery requirement. The possible real-person service remains outside this decomposition. These approvals do not establish implementation readiness; use [create-features](../../.agents/skills/create-features/SKILL.md) for later feature work.
